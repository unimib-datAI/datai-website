ABSTAT: the official [euBusinessGraph deliverable](https://www.eubusinessgraph.eu/wp-content/uploads/2019/08/D3.3_v2.0.pdf) identifies the Bitbucket repository. Its API confirms it is a public Git repository. The old abstat.disco.unimib.it website did not resolve during verification and is omitted.

SemT-X documentation identifies the current framework name; its frontend and backend README files link to that documentation. SemT-py is listed separately as the Python library, matching its README, rather than labelling that repository as the web interface.

Project websites include official documentation sites. For tools without a verified dedicated website, only the Git repository is shown. MammoTab25 is explicitly labelled as a dataset with code. Research retains the Eventour dataset record and the scientific publication links.
